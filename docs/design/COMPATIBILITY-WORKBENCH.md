# Retained local compatibility workbench

This extends the approved platinum/navy workspace across the dashboard. Mantine controls keep the established Plex type scale, 13px minimum text, indigo selection, and Mono measured values. No new visual direction is introduced.

The left fixture book selects an exact saved revision. A central editor declares source format, target format, request or stream operation, model label and suitable-input consent. An adjacent result inspector shows route evidence, bounded shape/tool/event checks and exact input/output JSON. Run history selects an immutable receipt. Capability evidence is grouped from actual retained local runs and never describes provider readiness. Narrow view stacks the book, editor and inspector with locally scrollable JSON and tables.

Fixtures are explicitly synthetic or operator-submitted suitable local test content. No historical traffic is replayed or imported automatically. Known credential fields and token patterns are refused, not silently redacted. That validation does not promise to identify every secret. Inputs are limited to64KiB, depth24 and256 stream events; results to512KiB. At most200 fixture IDs,2000 revisions and2000 runs are retained; capacity refuses further admission without deleting evidence. A single isolated worker has four waiting slots and a3second execution deadline. Cancel stops the worker and retains a terminal receipt. Interrupted work is marked interrupted and never replayed.

The engine uses maintained request/response translators and describes actual registered edges, including direct, OpenAI pivot, same-format normalization and missing paths. Request envelope/tool schema checks are bounded structural checks, not provider schema validation or proof of semantic equivalence. Stream input is an ordered synthetic event list, not a recorded network/SSE transport. The local worker receives no credentials, uses no account lookup and runs without filesystem-write, network or subprocess permission. Authenticated executor and full gateway scopes remain unavailable here.

API lives under `/api/admin/compatibility`. Every route enforces existing operator authentication, and writes retain the existing loopback boundary. Fixture updates require exact revision, archival creates a retained revision, and all lookups enforce installation-operator ownership. Exact run admission pins fixture ID/revision/hash in one transaction. Run selection and paginated history survive reload through IDs, with no first-page completion claim.

Validation includes actual database ownership/revision/FK behavior; real translator request and stream checks; worker cancellation, timeout, queue and permission failure; authenticated API refusal; and compiled save/reload/run/result/history/export plus conflict and unavailable flows. Browser evidence uses private synthetic data at1440/1920/390 and preserves all existing previews.
